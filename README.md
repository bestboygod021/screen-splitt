# Screen Splitt v1.0.0
نرم‌افزار رایگان و اوپن سورس مدیریت و اسپلیت کردن پنجره‌های ویندوز، با قابلیت نگهداری تمام پنجره‌ها در یک محیط همیشه در بالا.

## قابلیت‌های اصلی
✅ **همیشه در بالاترین سطح:** پنجره Screen Splitt همیشه بالای تمام پنجره‌های دیگر باقی می‌ماند، حتی وقتی روی برنامه‌های دیگر کلیک می‌کنید
✅ **چهار حالت چیدمان مختلف:** تک پنجره، دو قسمتی عمودی، دو قسمتی افقی، چهار قسمتی (تا 4 پنجره همزمان)
✅ **جداکننده‌های قابل کشیدن:** می‌توانید نسبت سایز بخش‌های مختلف را با کشیدن خط جداکننده تغییر دهید
✅ **میزبانی پنجره‌های خارجی:** می‌توانید هر برنامه باز دلخواهی (نوت‌پد، اکسپلورر، مرورگر، ماشین حساب و ...) را داخل نرم‌افزار الحاق کنید
✅ **حفظ کامل عملکرد پنجره‌ها:** تمام قابلیت‌های برنامه‌های میهمان (کپی/پیست، کلیک راست، منوها، تایپ) کاملاً کار می‌کند
✅ **هدر اختصاصی هر کادر:** عنوان پنجره در بالای هر کادر نمایش داده می‌شود و دکمه بستن سریع وجود دارد
✅ **افکت مدرن Mica:** ظاهر یکپارچه با ویندوز 11 با افکت شیشه‌ای مات
✅ **شروع خودکار با ویندوز:** می‌توانید تنظیم کنید که نرم‌افزار با روشن شدن کامپیوتر خودکار باز شود
✅ **پشتیبانی از تم تاریک و روشن**
✅ **ذخیره خودکار آخرین تنظیمات و چیدمان استفاده شده**
✅ **پاکسازی هوشمند:** هنگام بستن نرم‌افزار تمام پنجره‌های میهمان به طور خودکار به حالت عادی به دسکتاپ بازگردانده می‌شوند

## راهنمای اجرا
### پیش‌نیازها
- ویندوز 10 نسخه 1903 به بالا یا ویندوز 11
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) (فقط برای اجرای نسخه وابسته به فریم ورک)

### اجرا از طریق سورس کد
```powershell
git clone https://github.com/your-username/screen-splitt.git
cd screen-splitt/ScreenSplitt
dotnet restore
dotnet run
```

### ساخت نسخه اجرایی مستقل (نیازی به نصب دات نت ندارد)
```powershell
cd ScreenSplitt
dotnet publish -c Release
```
فایل اجرایی نهایی در مسیر زیر ساخته می‌شود:
```
ScreenSplitt/bin/Release/net8.0-windows/win-x64/publish/ScreenSplitt.exe
```
فقط کافیست این فایل را اجرا کنید، نیازی به نصب هیچ برنامه دیگری نیست.

## راهنمای استفاده
1. نرم‌افزار را اجرا کنید، پنجره Screen Splitt در مرکز صفحه باز می‌شود و همیشه روی سایر پنجره‌ها باقی می‌ماند.
2. از دکمه‌های بالای صفحه چیدمان مورد نظر خود را انتخاب کنید (تک پنجره، دو قسمتی و ...).
3. روی هر کادر خالی کلیک کنید، لیست تمام پنجره‌های باز در سیستم نمایش داده می‌شود، پنجره مورد نظر را انتخاب کنید تا داخل کادر الحاق شود.
4. می‌توانید با کشیدن خطوط جداکننده بین کادرها، سایز هر بخش را تغییر دهید.
5. برای جداسازی هر پنجره، روی دکمه ✕ در گوشه بالای کادر مربوطه کلیک کنید.
6. از دکمه چرخ‌دنده (تنظیمات) می‌توانید شروع خودکار با ویندوز و تم تاریک/روشن را تغییر دهید.

## نکات فنی
- این نرم‌افزار از توابع بومی Win32 API شامل `SetParent`، `SetWindowLong` و `MoveWindow` برای الحاق پنجره‌ها استفاده می‌کند.
- هیچگونه کد یا داده‌ای از پنجره‌های میهمان خوانده یا ذخیره نمی‌شود، تمام عملیات ورودی/خروجی مستقیماً توسط خود برنامه میهمان پردازش می‌شود.
- این نرم‌افزار به صورت کاملاً آفلاین اجرا می‌شود و هیچ ارتباط اینترنتی ندارد.
